# 工事工程表ツール（協電機工）

工事の工程表を、ブラウザだけで作って印刷できる無料ツールです。
インストール不要・ネット接続なしでも動きます（ファイルを開くだけ）。

**公開URL：** https://masayukif.github.io/kyoden-koutei-tool/

## 2種類の工程表が作れます

- **月間工程表（日付ベース）** … 1ヶ月単位のいつもの工程表。機械設備・電気設備に対応
- **1日・時間軸工程表（時間ベース）** … 空調入替など1日〜数日で終わる工事を時間単位で

## ファイル構成

- `index.html` … ツール本体（これだけで完結）
- `manifest.webmanifest` / `icon-192.png` / `icon-512.png` / `icon.svg` … スマホ「ホーム画面に追加」でアプリ化するための部品

## 使い方

1. ブラウザ（Chrome / Edge / Safari）で開く
2. 「サンプルを入れて試す」で動きを確認（機械・電気・1日工程の3種類）
3. ⓪工程表の種類 → ①工事情報 → ②表示期間 → ③工種 → ④作業バー → 印刷（A3 / A4 横）

PDFで保存すると、ファイル名に工事名が自動で入ります（例：`○○工事_工程表_令和8年8月度.pdf`）。

## スマホ（iPhone / Android）

- **iPhone / iPad**：**Safari**で開く → 共有ボタン（□に↑）→「ホーム画面に追加」
- **Android**：**Chrome**で開く → 右上の⋮ →「ホーム画面に追加」

※ わざと全画面アプリにしていません。全画面にすると印刷・PDF保存ができなくなるためです。
